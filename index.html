How to use this

This page makes a card from an isiBheqe phrase and writes the Latin syllable under each shape. Seeing the shape and its syllable together is what helps someone learn to read the script.

What you can do here

1 · Build a new entry from scratchClick shapes on the keyboard to spell out the phrase. Each syllabeme gets a box under it. Type its Latin syllable in that box. Fill in the Entry details, then export.
2 · Bring in a code string from the original demo, using “Load pasted code”If a phrase was typed at isibheqe.org.za/demo, paste its code string into the box near the bottom and press Load pasted code. The glyphs appear here with empty Latin boxes, ready to fill in.
3 · Re-open a saved record and change itPress Open a saved file… and choose a JSON file. The glyphs, Latin syllables, language, gloss and scribe all come back. Change what you need to and export again.
4 · Hand a half-finished entry to someone elseDownload the JSON at any point and send it on. Whoever opens it carries on from where you stopped. This lets one person draw the glyphs and another supply the Latin for a language they know.
5 · Make a picture for WhatsAppCopy card to clipboard, then paste it into a chat. If copying does not work, use Download card as an image instead. The card is square, sized for WhatsApp and Status.
6 · Make a version for printDownload card as an SVG image gives a vector file. Its glyphs stay sharp at any size, so you can put the same entry into a printed phrasebook later without building it again.
7 · Send the phrase back to the original demoCopy code string puts the phrase on your clipboard in the form isibheqe.org.za/demo reads. Paste it there to check the rendering against the original tool.
8 · Check someone’s work syllable by syllableEach shape sits directly above its own Latin box, so you can tell exactly which syllable is wrong instead of only sensing that the phrase is off.

What a “code string” is

A code string writes the script as plain text. It is a list in square brackets, one item per syllable. Each item is the vowel, then the marks on it.

["a",["k"]]            the vowel a, plus the mark k         →  ka
["a",["k","•","w"]]    the vowel a, plus k, plus •, plus w   →  kwa
"a"                    a bare vowel with no marks at all    →  a

A whole phrase puts those items inside one outer pair of brackets, with " " standing for the space between words:

[["i",["n"]]," ",["a",["°"]],["ɛ",["ʃ"]]]

Being plain text, a code string travels inside a message or a spreadsheet cell, and rebuilds into the same glyphs wherever it lands. That is why the saved record keeps it.

Two things worth knowing

There is no “m” mark. Nasals use the ° modifier, so ma is ["a",["°"]], not ["a",["m"]]. If you type a mark the engine does not know, it drops it without warning.
You type the Latin yourself because it depends on the language. The same glyph is sha in isiZulu and xa in Xitsonga. The tool cannot know which you mean, and a guess would bury the very difference worth showing. Always set the Language field.

If something looks wrong

The note beside the syllabeme count tells you whether the card fits at full size, was scaled down, or has become too small to read. If it warns about size, split the phrase across two cards.

In the code string below the card, any syllable the engine cannot read sits on a red background. The engine drops marks it does not know without complaining, so that red highlight is the only place a bad mark shows itself.

If a pasted code string will not load, the message says what is wrong: a missing bracket, a curly quote, or the number of the syllable that is malformed. A long phrase edited by hand usually loses a ] somewhere in the middle, so look there first.
